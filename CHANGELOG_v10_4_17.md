## Архитектурное решение

Старый `.toprow` **скрыт CSS** (`display:none !important`), но остаётся в DOM — старый код продолжает без ошибок обновлять `#topSub`, `#saveState`, `#modeBtn`, `#themeBtn`. Новый `.v1417-bar` добавляется в `<header class="topbar">` через `injectTopbar()` (idempotent). `renderHeader()` обёрнут: сначала вызывает цепочку старых обёрток (они пишут в скрытые элементы), затем обновляет новые видимые элементы.

## А. Что убрано из шапки

- **«offline-ready»** — скрыт вместе с `.toprow`; приложение всегда офлайн-способно, метка не нужна.
- **Номер версии** (`v10.4.x`) — убран из видимой части шапки. Все 6 слоёв `renderHeader`-обёрток продолжают писать версию в скрытый `#topSub` (ломать нельзя) — до пользователя не доходит. В «О программе» жёстко прописан `v10.4.17`.
- **«сохраняю…/сохранено HH:MM»** — заменён тихим `✓` (`#v1417-save`): появляется на 1.7 с после `saveNow()`, гаснет. `markDirty()` скрывает его.
- **«Основной» / «Технический»** как текст — заменён иконкой `👁` (режим клиента) / `🔧` (внутренний). `applyTheme()` обёрнут для синхронизации иконки.

## B. Структура новой шапки

**Телефон (≤1023px) — две строки:**
```
Строка 1:  [B логотип] Замена фасадов          [🔧/👁]  [✓]  [⋯]
Строка 2:  ПРОЕКТ Новый проект ▾           [● проверить]
```

**Десктоп (≥1024px) — одна строка (flex без wrap, centerOrder=2):**
```
[B] Замена фасадов   ПРОЕКТ Новый проект ▾   [● проверить]      [🔧] [✓] [⋯]
```

Реализация: `flex-wrap` + `order` CSS. На мобайле `.v1417-center { flex: 0 0 100%; order: 3 }` → занимает отдельную строку. На ≥1024px `flex-wrap: nowrap; .v1417-center { order: 2; flex: 1 1 auto }` → встаёт между брендом и правыми кнопками.

## C. Элементы

1. **Лого + «Замена фасадов»** — кнопка, тап → `openProjectsModal()`. Текст из `state.appName` (по умолчанию «Замена фасадов»), настраивается.
2. **Проект: {имя} ▾** — кнопка, тап → `openProjectsModal()`. Объединяет старые «Проект» + «Проекты» в один элемент. Имя из `projectTitle()`.
3. **● статус** — кнопка с цветной точкой (зелёная/жёлтая/красная), тап → модалка «Проверка» со списком предупреждений из `validations()`. Цвет из `traffic().level`.
4. **👁/🔧** — переключатель режима. Один тап, тост подтверждает. `title` атрибут = «Режим клиента / Внутренний».
5. **✓** — тихий flash после автосохранения (opacity 0→1→0). Не текст, не pill.
6. **⋯** — меню. Содержит:
   - Тема: ☀️ Светлая / 🌙 Тёмная / ◐ Авто (chips)
   - ⚙ Настройки (→ вкладка Настройки)
   - ↓ Экспорт JSON
   - ↑ Импорт JSON
   - ℹ О программе (версия `v10.4.17`, компания, приложение)
