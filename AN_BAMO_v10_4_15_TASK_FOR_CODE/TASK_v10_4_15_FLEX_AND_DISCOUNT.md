## БЛОК A — Скидка клиенту (НОВОЕ, главное)

### A1. Состояние
В `ensureV1415()`:
```
state.quote = state.quote || {};
state.quote.discount = state.quote.discount || { type:'none', value:0, reason:'' };
// type: 'none' | 'percent' | 'amount'
```

### A2. UI скидки
На вкладке **«Деньги»** и в блоке **«Итого»** (Быстро / Смета) добавить блок «Скидка клиенту»:
- Переключатель: Нет / Процент % / Сумма €
- Поле ввода значения
- Поле «Причина скидки» (необязательно, текст — например «постоянный клиент», «сезонная акция»)
- Live-пересчёт: показать «Цена до скидки», «Скидка −X €», «Цена к оплате»

### A3. Расчёт
Функция `applyDiscount(total)`:
- percent: `total * (1 - value/100)`
- amount: `max(0, total - value)`
- none: `total`
Скидка применяется к **итогу клиенту** (не к себестоимости). Маржа пересчитывается с учётом скидки (в техрежиме показать «маржа после скидки»).

### A4. Скидка в КП
В документе «КП для клиента» (`docHtml('kp')`) добавить строки перед итогом:
```
Стоимость по предложению:    1 888 €
Скидка (постоянный клиент):   −188 €
─────────────────────────────────
К оплате:                    1 700 €
```
Если скидки нет — строки не показывать. Клиент должен видеть, что ему дали скидку — это продаёт.

## БЛОК B — Гибкость каталога (вывести существующее на видное место)

В коде УЖЕ есть: флаги `active`/`show` на позициях, действия `priceToggleActive`/`priceToggleQuote`, `customPriceItems` с add/duplicate/delete. Задача — сделать это удобным, а не строить заново.

### B1. Экран «Что показывать клиенту» в Настройках
Новая секция Настройки → Прайс → **«Видимость позиций»**:
- Список всех категорий (Фасады / Столешницы / Фурнитура / LED / Доп.работы / Услуги)
- У каждой позиции — переключатель **ON/OFF** (один тап)
- OFF = позиция скрыта из Сметы/Быстро/Улучшений, но не удалена (данные целы)
- ON = доступна для добавления в заказ
Используй существующий `priceToggleActive`. Просто собери все позиции в один список с тумблерами.

### B2. Быстрое добавление позиции в каждой категории
В каждой группе каталога — кнопка **«＋ Своя позиция»** (фасад поставщика, услуга и т.д.):
- Поля: название, единица, цена клиенту, себестоимость (необяз.)
- Сразу попадает в каталог и доступна в Смете
Используй существующий `priceAddCustom` / `addCustomPriceItemV10465`.
